# Work with Paddle

1. Read the Paddle integration section in `AGENTS.md`.
2. Check current Paddle documentation through `paddle-docs` when available, or official Paddle documentation otherwise.
3. Keep development in Paddle sandbox and use the official SDK for the language.
4. Verify webhook signatures before using payload data.
5. Ask for explicit confirmation before destructive Paddle account changes.
6. Run the relevant client or Edge Function checks and report any unverified external behavior.
